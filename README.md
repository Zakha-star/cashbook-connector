
LedgerMatch
A bank reconciliation assistant built to streamline the manual matching process between cashbook entries and bank statement transactions — inspired by real-world reconciliation workflows used in accounting traineeships.
About
LedgerMatch automates one of the most time-consuming parts of bookkeeping: matching cashbook entries to bank statement transactions. Instead of manually cross-checking line by line, users can input both sets of records and let the app identify matches, flag possible matches, and highlight unresolved discrepancies.
This project was built as part of the CAPACITI AI Skill Accelerator Programme, using Lovable for AI-assisted development.
Features
Dual entry input — add cashbook and bank statement transactions manually or paste in bulk
Automated matching — transactions matched by amount, date proximity, and reference number
Three-tier results — Matched, Possible Match, and No Match categories
Reconciliation summary — cashbook balance, bank balance, and reconciled closing balance at a glance
Manual resolution — mark unmatched items as resolved once verified
